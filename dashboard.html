Casos de teste

ID do Caso de Teste Tipo de Teste Caso de Teste (CT) O que foi testado Como foi testado (entradas/valores de base) Resultado Esperado Resultado Obtido Status do Teste
CT-01 Requisitos Cadastro com sucesso Cadastro de funcionário com todos os dados válidos. Nome, CPF, endereço, e-mail, senha, cargo e demais campos válidos. O funcionário deve ser cadastrado corretamente.
CT-02 Bloqueio Campo obrigatório vazio Tentativa de cadastro sem preencher um campo obrigatório. Deixar o campo Nome ou E-mail vazio e tentar cadastrar. O sistema deve impedir o cadastro e informar o campo obrigatório.
CT-03 Bloqueio Formato de e-mail inválido Validação do formato do endereço de e-mail. Informar um e-mail inválido, como usuario@ ou usuario.com. O sistema deve rejeitar o e-mail inválido e solicitar a correção.
CT-04 Bloqueio Seleção de múltiplos turnos Verificação da seleção de turnos no cadastro. Tentar selecionar mais de um turno, quando a regra permitir apenas um. O sistema deve impedir uma seleção incompatível com a regra definida.
CT-05 Bloqueio Validação de salário negativo Validação do valor informado no campo salário. Informar um valor negativo, como -500. O sistema deve impedir o cadastro com salário negativo.
CT-06 Requisitos Opções de cargo Verificação das opções disponíveis no campo Cargo. Abrir a lista de cargos e verificar se existem pelo menos quatro opções. O campo deve apresentar pelo menos quatro opções de cargos.
CT-07 Requisitos Formatação do salário Verificação da apresentação do salário em reais. Informar um salário válido, como 2500. O valor deve ser apresentado no formato de moeda brasileira (R$).
CT-08 Requisitos Exibição da identidade visual Verificação da exibição da logo da G&A VISION. Acessar a página do sistema e observar o cabeçalho. A logo deve ser exibida corretamente, sem distorções ou falhas.

Orientações

Execute cada caso de teste no sistema de cadastro. Depois, registre o resultado obtido e selecione PASSOU ou FALHOU. Os indicadores serão atualizados automaticamente.
